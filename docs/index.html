Install

  1. Open the latest successful suite run and download av-flipper-suite.
  2. With qFlipper, copy apps/*.fap to SD Card/apps/GPIO/ and infrared/*.ir to SD Card/infrared/.
  3. Check each tool's README for its wiring and for what has been tested on real hardware.
